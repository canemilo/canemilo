## Desarrollo

Actualmente profundizo en patrones de diseño y arquitecturas empresariales, moviéndome tanto en entornos NoSQL (JavaScript/TypeScript) como en relacionales y fuertemente tipados (Java). En mi día a día, aplico:

* **Arquitectura Limpia (Clean Architecture):** Separación estricta de responsabilidades usando Patrón Repositorio y Capas de Servicio para que el dominio del negocio sea independiente del framework o la base de datos.
* **Backend Versátil y Tipado:** Capacidad para diseñar APIs sólidas tanto con **Node.js** como con **Java Spring Boot**, adaptando la herramienta a las necesidades de escalabilidad del proyecto.
* **Seguridad (Security-First):** Implementación de flujos de autenticación robustos (JWT HTTP-only), autenticación de doble factor (2FA), encriptación de grado médico (AES-256) y control de acceso por roles (RBAC).
* **DevOps e Infraestructura:** Control de versiones avanzado con **GitHub** y aislamiento de entornos utilizando contenedores **Docker** para garantizar que el software funcione igual en mi máquina que en producción.

##  Proyecto : DathU

Todo este conocimiento lo estoy materializando en **DathU**, mi proyecto principal. 

Es un **Motor de Analítica Avanzada y Sistema de Gestión Clínica** de alto rendimiento estructurado como Monorepo. Más que un CRUD, es un ecosistema complejo que gestiona agendas dinámicas, flujos de triaje de pacientes en tiempo real (100% WebSockets), validaciones estrictas con Zod entre fronteras, y un manejo de historiales clínicos que prioriza la privacidad absoluta mediante criptografía.
