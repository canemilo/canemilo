##  Proyectos

Actualmente divido mi tiempo entre mi formación y el desarrollo de varios proyectos propios, explorando diferentes arquitecturas y casos de uso:

*   **DathU:** Desarrollo de un Motor de Analítica Avanzada y Sistema de Gestión Clínica estructurado como Monorepo. Comunicaciones en tiempo real (WebSockets), validaciones estrictas (Zod) y aplico el principio *Security-First* (flujos JWT, encriptación AES-256, 2FA y RBAC).
*   **Meet Málaga:** Plataforma web construida con Angular y Firebase orientada a la reserva de rutas y descubrimiento del turismo local.
*   **Prokope:** Desarrollo de una *Progressive Web App* (PWA) enfocada en el registro, métricas y seguimiento de rutinas de entrenamiento.
*   **Wifi Guardian:** Experimentación con aplicaciones de escritorio orientadas a la monitorización de dispositivos y el escaneo de seguridad de redes locales.

>  **Técnico:** Docker para garantizar la portabilidad.
