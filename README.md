## Lo que estoy construyendo: DathU

Mi proyecto : **DathU**: un Motor de Analítica Avanzada y Sistema de Gestión Clínica pensado para ser *Production-Ready*.

* **Arquitectura Monorepo:** Frontend, Backend y una capa `shared` como única fuente de verdad.
* **Contratos (DTOs):** Uso Zod tanto en el cliente como en el servidor
* **Tiempo Real:** Agendas sincronizadas y notificaciones mediante WebSockets.
* **Backend :** Separación real de responsabilidades usando Patrón Repositorio y Capa de Servicios.
* **Seguridad:** Autenticación con 2FA, encriptación AES-256 y control de acceso por roles (RBAC).

## Stack Principal

Aunque aprendo lo que el proyecto requiera (Java, C#, etc. por el grado de DAM):

* **Frontend:** React 19, Material-UI (MUI), Tailwind Css.
* **Backend:** Node.js, Express.
* **Datos:** MongoDB (Mongoose).
* **Ecosistema:** Git, Zod, Socket.io, JWT.
